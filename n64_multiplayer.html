1. Everyone picks the same game

Every player downloads this ROM — there is no host doing it for you, because there is no video stream. That is the trade that makes your controller feel local.

Read it out or send it. Everyone else picks the same game, taps I have a code, and types this in.

Pressing Start opens the emulator and the room. Nobody's game actually begins until every player's console has finished loading — that is the start barrier, and it is what makes frame 0 the same moment for everybody.
