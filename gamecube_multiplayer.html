GameCube — Online Play

Not available on this console yet

Online play here used to work by streaming: one machine ran the game and sent everyone else a video of it. That is cancelled — every player should run the game on their own device, so their controller is as immediate as it is offline.

The streaming version has been removed rather than switched off, so there is nothing left to fall back to by accident.

Why the GameCube specifically

Deterministic play needs a way to run exactly one emulated frame on every machine with the agreed input applied first. This console does not have one on its shipping path: it runs the CPU and the graphics on two separate threads, and the call that would normally advance one frame does not advance the CPU at all — the CPU simply runs continuously on its own thread.

Holding the frame loop there would freeze the picture while both machines kept playing on independently, drifting apart without any sign of it. A session that looks right and is silently out of sync is worse than no session, so this is being built properly rather than approximated.

It works on the Nintendo 64 today

Every player runs their own core, in step, from the first frame — only controller input crosses the network.
