This page is an emulator: it compiles and runs a console's own code in your browser, so it cannot work without JavaScript and WebAssembly. There is no reduced version to fall back to.

Turn JavaScript on for this site — or allow it in your content blocker — and reload. If you are in a private window with scripting restricted, a normal window will work.
